# Deep Learning Experiments

A collection of experiments exploring neural network architectures, model development, hyperparameter optimization, and evaluation across classification, regression, image recognition, and generative modelling.

## Experiments

| Model | Focus |
|---|---|
| [CNN Object Recognition](CNN-Object-Recognition/) | Convolutional neural networks, transfer learning with VGG16, product image classification, and visual similarity retrieval. |
| [DCGAN MNIST](DCGAN-MNIST/) | Generative adversarial learning for handwritten-digit synthesis, including architecture tuning and image-quality evaluation. |
| [Ensemble Learning for Dota 2](Ensemble-Learning-Dota-2/) | Stacking ensemble combining deep neural networks and LightGBM with logistic regression for match outcome prediction. |
| [MLP MNIST](MLP-MNIST/) | Multilayer perceptron for corrupted handwritten-digit classification, exploring network architecture, regularization, and hyperparameter optimization. |
| [MLP Wine Quality](MLP-Wine-Quality/) | Multilayer perceptron for wine quality regression, exploring network depth, dropout regularization, and hyperparameter tuning using physicochemical attributes. |
