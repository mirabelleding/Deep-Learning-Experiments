# CNN Object Recognition

An experiment in image classification and visual product retrieval using convolutional neural networks and transfer learning.

The project investigates product recognition using images from the Stanford Online Products dataset. It combines a pretrained VGG16 feature extractor with additional convolutional and dense layers for product classification and explores retrieving visually similar products.

## Methodology

- Investigate CNN architecture choices, including convolutional filters, kernel sizes, strides, and padding.
- Tune dense layers, learning rate, and training duration.
- Apply data augmentation to address overfitting.
- Use transfer learning with VGG16 for product-image features and similarity-based retrieval.
- Examine predictions and retrieval examples, including misclassifications.
