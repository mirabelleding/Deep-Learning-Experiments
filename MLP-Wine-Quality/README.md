# MLP Wine Quality

Wine quality prediction using a Multilayer Perceptron (MLP) for regression on physicochemical measurements.

The project explores neural network architecture and hyperparameter optimization to estimate numerical wine quality ratings from attributes including acidity, residual sugar, sulfur dioxide, pH, sulphates, and alcohol content.

## Methodology

- Preprocess and scale numerical input features.
- Develop feedforward MLP architectures for wine quality regression.
- Optimize hidden-layer dimensions, dropout rates, and learning rates.
- Evaluate predictive performance using mean squared error (MSE) and mean absolute error (MAE).
- Apply early stopping and compare model configurations to assess predictive performance.
