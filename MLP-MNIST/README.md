# MLP MNIST

Handwritten-digit classification using a Multilayer Perceptron (MLP), with an emphasis on architectural optimization and model performance under corrupted-image conditions.

The project investigates how network capacity, regularization, and training configurations affect recognition accuracy on the corrupted MNIST dataset.

## Methodology

- Evaluate the baseline model using classification accuracy, loss, and confusion matrices.
- Optimize hidden-layer dimensions, dropout rates, and learning rates.
- Investigate additional hidden layers and L2 regularization.
- Apply early stopping to determine the training duration.
- Analyze misclassified digits to identify recurring classification errors.
